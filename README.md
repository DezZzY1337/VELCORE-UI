# VELCORE UI — Wave GUI-only

GUI-only порт интерфейса Axon Hub на Wave UI. В репозитории нет игровых обработчиков: кнопки и переключатели создают интерфейс, а не ESP, aimbot и другие игровые эффекты.

## Структура

- `Wave.lua` — исходный упакованный Wave UI, не изменяется без необходимости.
- `Layout.lua` — таблица из 169 элементов интерфейса (названия, ID, значения по умолчанию, вкладки и секции). Для изменения меню в первую очередь редактируйте этот файл.
- `Menu.lua` — создаёт 7 вкладок, использует Wave и Layout, подключает менеджеры.
- `SaveManager.lua` — конфигурации при наличии файлового API.
- `InterfaceManager.lua` — оформление и интерфейсные настройки.
- `Loader.lua` — входная точка; загружает Menu.lua, который загружает остальные модули.

## Запуск (только если код доступен без авторизации)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/DezZzY1337/VELCORE-UI/main/Loader.lua"))()
```

**Важно:** сейчас репозиторий приватный. Публичный raw URL не работает без авторизации. Не включайте GitHub personal access token в клиентский Lua-код. Для удалённой загрузки выберите публичный источник файлов **после проверки прав на распространение Wave**, либо используйте локальную сборку.

## Зависимости и ограничения

1. Требуется клиентское окружение Roblox с поддержкой используемых Wave API; вызовы `game:HttpGet`/`loadstring` зависят от среды запуска.
2. Конфиги требуют файловые API: `readfile`, `writefile`, `isfile`, `isfolder`, `makefolder`, `listfiles`, `delfile`. В отсутствие API сохранение отключается.
3. Внутри Menu.lua игровые callbacks пустые. Игровые функции не перенесены.
4. Офлайн-проверка структуры не является тестом работоспособности в Roblox.
5. Перед переводом в Public проверьте лицензию Wave UI, права на публикацию и безопасность стороннего кода.

## Редактирование

В `Layout.lua` меняйте свойства строк `title`, `default`, `values`, `min`, `max`, `tab`, `side`, `section`. Не изменяйте `id` без необходимости — он используется для профилей настроек.
